# Hiten Clip AI

A browser-based video clipping starter built for GitHub Pages.

## Features
- Upload a video locally and preview it
- Select a clip start point
- Choose 30, 60, or 90 seconds
- Create and download clips in supported desktop browsers

## Current limitations
This starter is a manual clipper. AI highlight detection, YouTube link importing, automatic subtitles/transcription, 9:16 smart cropping, accounts, and batch exports are not connected yet. Direct clipping of YouTube URLs requires a permitted video source and processing backend.

## Deploy with GitHub Pages
1. Open repository **Settings**.
2. Choose **Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then click Save.
5. Wait for GitHub Pages to publish.
